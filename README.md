# Onboarding Form

Multi-step employee onboarding form built with Next.js, TypeScript, Tailwind, react-hook-form and Zod.

## Stack

- Next.js (App Router) + TypeScript (strict)
- Tailwind CSS
- react-hook-form + Zod

## Run locally

```bash
npm install
npm run dev
```

Scripts: `npm run build`, `npm run lint`, `npm run format`.
